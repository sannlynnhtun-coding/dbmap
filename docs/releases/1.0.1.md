# DBMaps Desktop 1.0.1

Use the original DBMaps logo from `public/favicon.svg` for the Windows app,
title bar/taskbar, installer, Start menu shortcut and `.dbml` file association.
The artwork is converted to a multi-size Windows icon without redesigning it.

Includes the same offline editor and schema-plus-layout `.dbml` documents as
1.0.0. Download `DBMaps-Setup-1.0.1-x64.exe`; WebView2 and the native Visual C++
runtime are included. Verify the installer using `SHA256SUMS.txt`.

The installer remains unsigned. Windows 11 has not been separately tested.
