# DBMaps Desktop 1.1.1

A fresh Windows x64 build from main commit `829125609cb57929159fac55353433b5e74651ce`, with desktop/package/resource/installer versions aligned to 1.1.1. This release uses main, not the separate unmerged workspace-navigation branch.

The original DBMaps SVG and Windows ICO hashes are unchanged. The installer includes the offline editor, Fixed Version WebView2 runtime 157.0.4341.42, Visual C++ runtime files and third-party notices. No automatic updater is included.

## Validation

- All 22 JavaScript tests and 5 Rust tests passed, with no skipped tests.
- TypeScript check and production web/native builds passed.
- Native renderer integration passed: document load, actual table drag/save, raw schema preservation, rename/layout retention, visual edits and native disk save.
- Native Unicode Save As produced byte-identical content; Open and cancellation were verified.
- Rust tests verified external-change/read-only protection and failed replacement safety.
- Clean, network-disabled Windows 10 Sandbox passed fresh install, bundled-runtime document launch, upgrade from 1.1.0, executable-version verification, reinstall and uninstall, preserving a document outside the installation folder.

## Download

Use `DBMaps-Setup-1.1.1-x64.exe`. `example.dbml` includes a sample schema and layout. Verify both assets against `SHA256SUMS.txt`.

The installer is unsigned; Windows may show a warning. Windows 11 has not been separately tested. Existing user schemas are not removed during uninstall.
