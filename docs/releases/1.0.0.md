# DBMaps Desktop 1.0

Windows x64 desktop edition of DBMaps with a bundled offline WebView2 runtime.

- Install per user and launch from the Start menu without a server or account.
- Open `.dbml` documents from Windows Open with, or use the document toolbar.
- Save schema, table positions and diagram display settings in one UTF-8 `.dbml` file.
- Use Ctrl+O, Ctrl+S, Ctrl+Shift+S and Ctrl+N for file operations.
- Preserve schema text on layout-only saves and positions on unambiguous table renames.
- Confirm unsaved changes before replacing or closing documents. Failed writes and externally changed files do not silently overwrite the original.
- Bring existing web projects over using Export Full Project Backup and Import Project Backup, then Save As `.dbml`.

## Downloads

Run `DBMaps-Setup-1.0.0-x64.exe`. WebView2 and the native Visual C++ runtime DLLs
are included; installation and editing do not require an internet connection.
Use `SHA256SUMS.txt` to verify the installer. Open `example.dbml` to try a schema
with a saved layout. Windows default file associations are left for you to choose.

## Known limits

- The installer is unsigned, so Windows may show a warning.
- Layout is stored in a leading DBML comment. Other tools may remove that comment.
- Visual schema edits use DBMaps' existing generator; review the result when using syntax outside its supported subset. Layout-only edits preserve schema text.
- The document does not include workspace folders or history snapshots. Save each workspace project separately.
- The bundled Fixed Version WebView2 runtime does not update itself; runtime updates require a new app release.
- This release targets Windows x64. macOS, Linux, cloud sync and automatic updates are outside this release.
