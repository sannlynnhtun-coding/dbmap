# Desktop icon source

`DBMaps.ico` is a format conversion of the existing `public/favicon.svg`.
No artwork was redrawn or generated. The ICO contains transparent PNG frames
at 16, 24, 32, 48, 64, 128 and 256 pixels. The executable, window, installer,
Start menu shortcut and `.dbml` association all use this same icon.

Original SVG SHA-256:
`05909cd81322ac876b2e3e7efda69148cf7088e602bf5af1fdfe1acae7992ede`

Regenerate the ICO from the original SVG when the brand asset changes.
